# Security policy

Do not submit credentials, private keys, personal data, customer records, or sensitive production logs in issues or pull requests.

For a suspected vulnerability, contact the repository owner through a private security reporting channel. Include affected version, reproduction steps, impact, and mitigation if known. Do not publicly disclose an exploitable issue before coordinated remediation.

This is an initial engineering scaffold, not a certified financial system. Do not connect it to production payment, settlement, custody, or signing systems without an independent security review and formal approval.
